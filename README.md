🔥 Nether Launcher

A custom Android Minecraft launcher based on "Mojo launcher and pojav launcher" (https://github.com/MojoLauncher/MojoLauncher).

Nether Launcher aims to provide a familiar Minecraft Java Edition launching experience on Android, with a custom Nether-themed design and additional improvements developed for the project.

✨ Features

- 🎮 Minecraft Java Edition launcher for Android
- 🔥 Custom Nether-themed interface
- 🌑 Dark-themed UI
- ⚙️ Minecraft version and launcher settings
- ☕ Java runtime support
- 🎨 Custom launcher branding
- 📱 Designed for Android devices

🛠️ Development

Nether Launcher is currently based on the "v3_openjdk" branch of the upstream project.

The project is being customized with:

- Nether Launcher branding
- Custom colors and UI
- Custom icons and artwork
- Launcher improvements
- Additional features planned for future releases

📦 Building

The Android application is located in:

app_pojavlauncher/

The project uses Gradle and Java 17.

A debug APK can be built with:

gradle :app_pojavlauncher:assembleFullDebug

The project also includes GitHub Actions for automated Android builds.
